## 修复方案

### 需要修改的文件

1. **`backend/sync_engine.py`**
   - 在 `sync()` 方法中，当 `delete_sync=True` 时：
     - 本地不存在但远端存在 → 删除远端文件
     - 远端不存在但本地存在 → 删除本地文件

2. **`backend/sync_routes.py`**
   - 创建/编辑任务接口，接收 `delete_sync` 字段
   - 写入数据库 `sync_tasks` 表

3. **`backend/database.py`**
   - `sync_tasks` 表新增 `delete_sync` 字段（ INTEGER DEFAULT 0）

4. **`frontend/src/views/Tasks.vue`**
   - 任务配置表单新增"启用删除同步"勾选框
